### Title
### Virtual Calculator: GUI Calculator using Python and Tkinter

### Introduction
Virtual Calculator is a simple desktop application that implements a basic arithmetic calculator with a graphical user interface. It demonstrates how to build interactive GUI programs in Python using Tkinter, including button-driven input, expression evaluation, and real-time display updates.

### Task performed
Accept user input for numbers and operations through on-screen buttons and update the display accordingly.

Evaluate arithmetic expressions (such as addition, subtraction, multiplication, and division) when the equals button is pressed and show the result, while also providing clear and reset functions.

### Implementation details
Technology stack

Python 3.12

Tkinter
